3. See the PostGIS SQL

Key concept: ST_DWithin selects points within a radius; ST_Distance calculates distance so results can be ranked. The SQL is a template for tables with real WGS84 coordinates.

For class use: synthetic points, simplified miles and fictitious station names. No live maps, geolocation or external APIs are used. In a real geospatial database, store station geometry as geometry(Point,4326), cast to geography for meter-based distance, and index the spatial column appropriately.
